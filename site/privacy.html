Privacy and disclosure

How this demonstration handles data

Demo status

This is a fictional demo project created to demonstrate Email Clarity’s implementation process. It is not client work, and no performance results are being claimed. Commonlight Studio, Lena Ortiz, and the webinar are fictional.

Public preview mode

The registration experience validates entered values and simulates a successful submission. It does not create a contact, send an email, or add anyone to a mailing list.

Controlled test mode

When enabled server-side, only exact addresses in a private environment allowlist can be sent to the dedicated Brevo demo list. All other addresses are rejected before any Brevo request is made.

Analytics

Optional analytics use fixed, non-identifying campaign events. Names, emails, organizations, and form values are never included. GA4 remains inactive unless a visitor allows analytics.

Current browser choice: Not chosen

External services

No Brevo, GTM, or GA4 resource is connected in the initial implementation. Those resources require separate approval and controlled configuration.
