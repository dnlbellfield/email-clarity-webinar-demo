Allowed

Controlled implementation values

  • Preview or test mode

Prohibited

Personal or entered data

  • Name or email address
  • Organization
  • Any form-field contents
  • Free text or arbitrary URL values
  • Production inquiry or lead events

Consent behavior

GA4 stays inactive until a visitor opts in.

The page records a default denied state. Anonymous demo events can be inspected locally, but they are pushed to the analytics data layer only after consent. GTM loads only when an approved container ID is present and consent has been granted.
